Akwad Nursery · تشغيل الشاشات + المالية والحسابات بالتفصيل

كيف تقرأ هذا الدليل؟

لكل شاشة نفس الترتيب:

  1. المسار — من أين تفتحها في القائمة
  2. ماذا ترى — الأرقام والجداول والتبويبات

هذا الدليل للشرح في الميتنج وللتشغيل اليومي — مبني على شاشات النظام كما هي.

1) لوحة التحكم

المسار القائمة → لوحة التحكم

ماذا ترى؟

  • بطاقات أرقام: أطفال نشطون، طاقم، فصول، حضور اليوم، بانتظار التسجيل، انصراف اليوم
  • إن عندك صلاحية اشتراكات: غير مدفوعة / تنتهي قريبًا
  • ثلاثة أعمدة أطفال: لم يحضروا بعد · داخل الحضانة · انصرفوا اليوم
  • قسم بوابة أولياء الأمور (رابط + QR) إن كانت الميزة مفعّلة

كيف تشتغل؟

  1. افتح اللوحة صباحًا لتتابع الوضع العام.
  2. من عمود «لم يحضروا»: اضغط تسجيل حضور للطفل.
  3. من عمود «داخل الحضانة»: اضغط تسجيل انصراف عند الاستلام.
  4. أو اضغط تسجيل حضور سريع للانتقال لشاشة الحضور.
  5. بوابة أولياء الأمور: انسخ الرابط / افتح / حمّل QR / ارفع شعار إن لزم.

بعد التنفيذ / قواعد

  • الطفل ينتقل بين الأعمدة تلقائيًا حسب الحضور/الانصراف.
  • لو كل الأطفال حضروا: رسالة «كل الأطفال سجّلوا حضورًا».

2) حضور وانصراف

المسار القائمة → حضور وانصراف

ثلاث تبويبات: تسجيل سريع | الأطفال | طاقم العمل

2.1 تبويب تسجيل سريع

ماذا ترى؟

  • بحث سريع بالاسم
  • لوحة اليوم للأطفال + لوحة للطاقم

كيف تشتغل؟

  1. ابحث عن الطفل أو الموظف بالاسم.
  2. اضغط حضور عند الوصول، وانصراف عند المغادرة.
  3. يمكن التسجيل مباشرة من بطاقات لوحة اليوم بدون بحث.

بعد التنفيذ

  • يتحدّث سجل اليوم فورًا وينعكس على اللوحة والتقارير.

2.2 تبويب الأطفال (متابعة أسبوعية)

ماذا ترى؟

  • شبكة أسبوع: اسم الطفل + خلايا الأيام (حاضر / إجازة / غائب) + ملخص يومي
  • تنقّل بين الأسابيع، بحث، فلتر فصل

كيف تشتغل؟

  1. اختر الأسبوع بالأسهم أو فلتر الفصل ثم تطبيق.
  2. تعيين أيام الحضور: حدّد أيام العمل الأسبوعية للحضانة.
  3. + تسجيل إجازة: الاسم، من، إلى، واختيار الأطفال → حفظ.
  4. إنشاء تقرير: اختر الأشخاص والفترة (وسبب الغياب إن لزم) → يفتح التقرير.

2.3 تبويب طاقم العمل

نفس فكرة المتابعة الأسبوعية لكن للموظفين (يحتاج صلاحية حضور الطاقم). بدون صلاحية: التبويب غير متاح.

حالات السجل المعتادة: حضور · انصراف · إجازة · غائب · لا يوجد سجل.

3) الأطفال

المسار القائمة → الأطفال

3.1 قائمة الأطفال

ماذا ترى؟

  • KPIs: إجمالي / نشطة / مؤرشفة
  • جدول: الطفل، الكود، الفصل، ولي الأمر، الحالة، إجراءات
  • بحث + فلتر فصل + + إضافة طفل

كيف تشتغل؟

  1. اضغط + إضافة طفل.
  2. عبّئ البيانات الأساسية: الاسم*، الجنس، تاريخ الميلاد، الفصل، صورة.
  3. القسم الصحي: حساسية، أمراض، ملاحظات، أدوية (اسم/جرعة/تكرار/وقت).
  4. ولي الأمر: الاسم*، العلاقة، الجوال*، هوية، بريد، عنوان، منطقة، مدينة.
  5. ارفع المستندات إن وجدت.
  6. احفظ — أو حفظ وإرسال دعوة البوابة إن كانت البوابة مفعّلة.

إجراءات الصف

  • عرض الملف · تعديل · أرشفة أو إعادة تفعيل

بعد التنفيذ / قواعد

  • بعد الإنشاء تفتح صفحة ملف الطفل.
  • الأرشفة تُخرج الطفل من الحضور اليومي النشط.
  • القائمة فارغة: رسالة تطلب إضافة أول طفل.

3.2 ملف الطفل (العرض)

ماذا ترى؟

  • البيانات الأساسية والصحية والأدوية وولي الأمر والمستندات
  • نشاط يومي + حضور آخر 14 يومًا

كيف تشتغل؟

  1. تعديل البيانات لتحديث الملف.
  2. إرسال دعوة البوابة لولي الأمر.
  3. تسجيل حضور/انصراف من الملف عند الحاجة.

4) أولياء الأمور

المسار القائمة → أولياء الأمور (تحتاج ميزة البوابة مفعّلة)

ماذا ترى؟

  • KPIs: إجمالي / بوابة مفعّلة / دخلوا
  • جدول: ولي الأمر، جوال، بريد، الأطفال، حالة البوابة، آخر دخول
  • رابط البوابة العام + بحث

كيف تشتغل؟

  1. ولي الأمر يُنشأ عادةً مع تسجيل الطفل (مش من شاشة مستقلة «إضافة»).
  2. من القائمة: افتح ملف ولي الأمر لترى أطفاله.
  3. إعادة الدعوة لإرسال رابط/توكن دخول البوابة من جديد.
  4. إلغاء الوصول يوقف دخول ولي الأمر للبوابة.

قواعد

  • لو البوابة مطفية: يطلع تنبيه → روح الإعدادات → مزايا الحضانة وفعّلها.

6) الفصول + يوم الفصل

المسار القائمة → الفصول

6.1 قائمة الفصول

ماذا ترى؟

  • KPIs: إجمالي / نشط / مؤرشف
  • جدول: اسم، سعة، فئة عمرية، أطفال مسجّلون، حالة

كيف تشتغل؟

  1. اضغط + إضافة فصل.
  2. عبّئ: اسم الفصل*، سعة*، فئة عمرية* (يمكن تحديد الكل)، الحالة.
  3. حفظ أو حفظ وإضافة جديد.
  4. من الصف: يوم الفصل أو تعديل.

6.2 يوم الفصل

المسار الفصول → يوم الفصل لفصل معيّن

ماذا ترى؟

  • أرقام: حضور، لم يصلوا، انصرفوا، السعة، النسبة
  • بطاقات أطفال بحالتهم: لم يحضر / حاضر / انصرف (وقد يظهر متأخر / مغادرة مبكرة)

كيف تشتغل؟

  1. سجّل حضور/انصراف فردي من بطاقة الطفل.
  2. أو حدّد مجموعة ثم تسجيل حضور/انصراف جماعي (بعد تأكيد).
  3. تصحيح لتعديل أوقات/حالة سجل خاطئ (يُسجَّل من صحّح ومتى).
  4. سجّل أنشطة الرعاية: وجبة / مزاج / حفاض / المزيد — تظهر لولي الأمر في البوابة.

قواعد

  • لو مفيش أطفال في الفصل: رسالة فارغة.
  • «متأخر» يظهر عند وجود مناوبة + مهلة مضبوطة.

7) الوحدات

المسار القائمة → الوحدات

ماذا ترى؟

  • تبويب نشطة / مؤرشفة + جدول: اسم، فئة عمرية، أهداف، حالة

كيف تشتغل؟

  1. + إضافة وحدة.
  2. اسم*، فئة عمرية*، أهداف* (زر إضافة هدف)، دروس اختيارية.
  3. حفظ — تظهر الوحدة عند جدولة درس في التقويم.

8) التقويم

المسار القائمة → التقويم

ماذا ترى؟

  • تقويم شهري/أسبوعي/يومي + فلاتر فصل ونوع الحدث

كيف تشتغل؟

  1. اضغط + إضافة للتقويم.
  2. اختر النوع أولًا: درس أو نشاط أو إعلان.
  3. عبّئ المشترك: تاريخ*، من*، إلى*، فصول و/أو حضور، ملاحظات، تكرار، روابط وسائط.
  4. إن درس: اختر الوحدة* والدرس*. إن نشاط/إعلان: عنوان*.
  5. حفظ — يظهر على التقويم (وللأهل في البوابة حسب الربط).
  6. اضغط على حدث موجود للتعديل أو الحذف.

9) الاشتراكات (رسوم الأطفال)

المسار القائمة → الاشتراكات
هذه شاشة التحصيل الأساسية — «فاتورة الرسوم» باسم اشتراك.

ماذا ترى؟

  • فترات عرض: الكل / يوم / أسبوع / شهر / سنة
  • KPIs: إجمالي، مدفوعة، غير مدفوعة، منتهية، ملغاة
  • جدول الاشتراكات + منطقة تذكيرات

كيف تشتغل؟ — إضافة اشتراك

  1. تأكد أولًا أن عندك خطة في الإعدادات → خطط الاشتراك.
  2. اضغط + إضافة اشتراك.
  3. اختر الطفل* والخطة*، راجع القيمة بعد الضريبة، أضف خصمًا إن وجد، حدّد بداية* ونهاية*.
  4. إن دُفع فورًا: فعّل «الاشتراك مدفوع» أو سجّل الدفع لاحقًا.
  5. احفظ.

كيف تشتغل؟ — من صف الاشتراك

  1. تسجيل الدفع → اختر نقدي / تحويل / بطاقة.
  2. تجديد → ينشئ اشتراكًا جديدًا للفترة التالية.
  3. إلغاء الاشتراك → الحالة ملغى.
  4. تذكير بالدفع (للكل أو للفرد) إن واتساب مفعّل.

بعد التنفيذ / قواعد

  • المبلغ النهائي = القيمة بعد الضريبة − الخصم (لا يقل عن صفر).
  • عند الدفع + تفعيل ميزة الترحيل المالي: يُنشأ قيد محاسبي تلقائيًا.

10) الإعدادات (5 تبويبات)

المسار القائمة → الإعدادات

10.1 الهوية البصرية

  1. ارفع شعار الحضانة.
  2. اضبط الألوان واسم العرض.
  3. احفظ — ينعكس على الواجهة/البوابة.

10.2 إعدادات الحساب

  1. عدّل: اسم الحضانة*، بيانات التواصل، العنوان، المنطقة/المدينة، بيانات المدير.
  2. احفظ. (إيميل دخول المدير يُدار من الملف الشخصي وليس من هنا.)

10.3 خطط الاشتراك

  1. أضف خطة: نوع*، اسم*، قيمة*، عملة (ر.س)، نسبة ضريبة*.
  2. النظام يحسب القيمة بعد الضريبة.
  3. الحذف عادةً يلغي تفعيل الخطة — الخطط تغذي شاشة الاشتراكات.

10.4 إدارة المناوبات

  1. أضف صف مناوبة: اسم + بداية + نهاية.
  2. احفظ — تؤثر على حساب «متأخر» في يوم الفصل وحضور الطاقم.

10.5 مزايا الحضانة

  1. فعّل/اطفِ: بوابة أولياء الأمور · واتساب · ترحيل الاشتراكات للمحاسبة.
  2. احفظ — التطبيق فوري على النظام.

11) المالية والحسابات — شرح تفصيلي لكل شاشة

قسم مستقل بالكامل: كل شاشة مالية بنفس أسلوب التشغيل (المسار · ماذا ترى · كيف تشتغل · القيود المحاسبية · القواعد).
قبل الشرح للعميل — 3 حقائق:
1) رسوم الأطفال من الاشتراكات، والمالية تحوّلها لقيود عند الدفع (إن فُعّلت الميزة).
2) المصروف يُحفظ مسودة ثم يُعتمد ليترحّل. أما سند القبض/الصرف والقيود اليدوية فتترحّل فور الحفظ.
3) أكواد شائعة: 1010 صندوق · 1020 بنك · 1030 ذمم مدينة · 2010 ذمم دائنة · 2030 ض.ق.م · 4000 إيرادات · 6000 مصروفات تشغيل.

11.0 كيف يشتغل الربط: اشتراك → قيد محاسبي

المسار الاشتراكات → تسجيل الدفع (بعد تفعيل المالية + ميزة ترحيل الاشتراكات + ربط طرق الدفع)

كيف تشتغل؟

  1. فعّل وحدة المحاسبة ومزية «ترحيل الاشتراكات للمالية» من الإعدادات.
  2. اضبط ربط طرق الدفع (نقدي/تحويل/بطاقة → حسابات الدليل).
  3. من الاشتراكات: سجّل الدفع أو أنشئ الاشتراك مدفوعًا.
  4. النظام ينشئ قيدًا بمرجع مثل NUR-SUB-{رقم}.
الجانبالحسابالمبلغ
مدينصندوق 1010 (نقدي) أو بنك 1020 (تحويل/بطاقة حسب الربط)إجمالي الاشتراك
دائنإيرادات مبيعات 4000الصافي بعد فصل الضريبة
دائنض.ق.م مستحقة 2030جزء الضريبة (إن وُجدت نسبة)

قواعد مهمة

  • لو الاشتراك مترحّل قبل كده: رسالة أن القيد موجود — مش هيتكرر.
  • المبلغ لازم أكبر من صفر.
  • عند الإلغاء: قيد عكسي بمرجع NUR-SUB-{رقم}-REV.
  • بدون الميزة: الاشتراك يفضل تشغيلي (مدفوع/غير مدفوع) بدون دفتر.

11.1 ملخص المالية

المسار المالية → ملخص المالية

ماذا ترى؟

  • فترات: هذا الشهر / هذا الأسبوع / اليوم / هذه السنة / الكل
  • بطاقات: التحصيلات · المستحقات · المصروفات · صافي الفترة (تحصيلات − مصروفات)
  • كذلك: منتهية الاستحقاق · منتهٍ (حالة) · صافي دفتر الأرباح (إن توفّر)
  • جدولان: المستحقات حسب ولي الأمر · أقرب اشتراكات غير مدفوعة (الطفل / حتى / المبلغ)

كيف تشتغل؟

  1. افتح الملخص واختر الفترة المناسبة للميتنج أو للمتابعة اليومية.
  2. اشرح للعميل الأرقام: كام دخل، كام لسه، كام صرف، والصافي.
  3. من الاختصارات انتقل إلى: الاشتراكات · تسجيل/عرض مصروف · تقرير الأرباح والخسائر.

قواعد

  • الشاشة للقراءة — مفيش إنشاء من هنا.
  • لو وحدة المحاسبة مطفية: يظهر تنبيه أن المحاسبة غير مفعّلة.
  • هذا الملخص تشغيلي؛ تقرير P&L أدق محاسبيًا لأنه من القيود.

11.2 لوحة المالية (لوحة المحاسبة)

المسار المالية → لوحة المالية

ماذا ترى؟

  1. اضغط سند قبض جديد.
  2. اختر العميل*، التاريخ*، المبلغ* (≥ 0.01)، ومرجع اختياري.
  3. اضغط حفظ السند.

القيد فور الحفظ

مديندائن

  • رسالة نجاح: تم حفظ السند وإنشاء القيد.
  • للشرح: رسوم الأطفال من الاشتراكات؛ سند القبض لتحصيلات العملاء/الذمم العامة.

11.6 سندات الصرف

المسار المالية → سندات الصرف

ماذا ترى؟

  • فلاتر: النوع (الكل/مورد/مصروف) · المورد · حساب المصروف · تواريخ · بحث
  • أعمدة: التاريخ · النوع · المورد/حساب المصروف · المرجع · فاتورة مشتريات · المبلغ · المستخدم

كيف تشتغل؟

  1. سند صرف جديد.
  2. اختر نوع السند*:
    • سند صرف مورد → اختر المورد* (وربط فاتورة مشتريات اختياريًا).
    • سند صرف مصروف → اختر حساب المصروف*.
  3. عبّئ التاريخ* والمبلغ* والمرجع.
  4. حفظ السند → قيد فوري.

القيود

النوعمديندائن
صرف موردذمم دائنة 2010خزينة/صندوق (غالبًا 1010)
صرف مصروفحساب المصروف المختارالخزينة

قواعد وأخطاء شائعة

  • لازم مورد مع نوع المورد، وحساب مصروف مع نوع المصروف.
  • لا تربط فاتورة مشتريات مع سند مصروف.
  • مبلغ السند لا يتجاوز رصيد الفاتورة؛ والفاتورة لازم تخص نفس المورد.
  • عند الربط بفاتورة: يتحدّث المدفوع وحالة الفاتورة.

11.7 البنوك (الحسابات البنكية)

المسار المالية → البنوك

ماذا ترى؟

  • فلاتر بحث/حالة · أعمدة: اسم البنك، رقم الحساب، العملة، حساب الدليل، الرصيد المحاسبي، الحالة

كيف تشتغل؟ — إضافة حساب

  1. إضافة حساب بنكي.
  2. تفاصيل البنك: اسم البنك*، اسم بالعربية، الفرع، سويفت.
  3. تفاصيل الحساب: رقم الحساب*، آيبان، اسم الحساب بالعربية، العملة* (ر.س / دولار…).
  4. جهة اتصال/هاتف اختيارية · تفعيل نشط/افتراضي · ملاحظات.
  5. إنشاء.

بعد الحفظ

  • يُنشأ حساب فرعي تلقائيًا تحت مجموعة البنوك (1020) ويُربط بالحساب البنكي.
  • الرصيد المحاسبي = من حركة الدليل (مش رقم يدوي منفصل).

11.8 التسوية البنكية

المسار المالية → التسوية البنكية

ماذا ترى؟

  • KPIs: إجمالي التسويات · معلق · إجمالي العناصر · تمت التسوية
  • فلتر حالة: جميع / معلق / تمت التسوية
  • أعمدة: رقم التسوية، الحساب البنكي، التاريخ، الرصيد، الفرق، الحالة

كيف تشتغل؟

  1. تسوية بنك جديدة.
  2. اختر الحساب البنكي* · تاريخ كشف الحساب* · الرصيد الافتتاحي (دفتري)* · الرصيد الختامي (كشف)*.
  3. إضافة بند لكل حركة: تاريخ، وصف، مرجع، مدين، دائن.
  4. إنشاء التسوية — تُحفظ كمسودة/معلق عادةً؛ راقب الفرق = كشف − دفتري.
التسوية ورقة مطابقة — لا تنشئ قيدًا بنفسها. الهدف تطابق كشف البنك مع الدفتر.

11.9 دليل الحسابات

المسار المالية → دليل الحسابات

ماذا ترى؟

  • KPIs: إجمالي الحسابات · إجمالي المدين · إجمالي الدائن · الفرق
  • فلاتر: بحث · نوع (أصل/خصم/مصروف/إيراد) · طي/توسيع الكل
  • شجرة: الرمز · اسم الحساب · النوع · مدين · دائن · الرصيد · الحالة · إجراءات

كيف تشتغل؟ — حساب جديد

  1. + حساب جديد.
  2. نوع الحساب* (أصل / خصم / حقوق ملكية / إيراد / مصروف).
  3. اسم الحساب* · الاسم بالعربية · الحساب الرئيسي (أب) · الوصف.
  4. خيارات: حساب بنكي · حالة النشاط. الرمز غالبًا تلقائي.
  5. إنشاء.

أخرى

  • تعديل من الصف (رمز/اسم؛ الرصيد الحالي للقراءة).
  • استيراد / تصدير CSV أو Excel + قالب استيراد.

11.10 القيود اليومية

المسار المالية → القيود اليومية

ماذا ترى؟

  • فلاتر: بحث · نوع · من/إلى · حساب في البند
  • أعمدة: رقم القيد · التاريخ · النوع · الوصف · مدين · دائن · الحالة (مسجّل) · إجراءات

كيف تشتغل؟ — قيد يدوي

  1. + قيد جديد.
  2. رأس القيد: تاريخ القيد* · المرجع · البيان · مرفقات · ملاحظات.
  3. أضف سطرين على الأقل: لكل سطر حساب* · وصف · مركز تكلفة · مدين أو دائن.
  4. استخدم إضافة سطر لأسطر إضافية.
  5. راقب شارة متوازن / غير متوازن.
  6. اضغط إنشاء القيد — الزر يتعطل لو المدين ≠ الدائن.
قاعدة ذهبية: لن يُحفظ القيد إلا إذا تساوى إجمالي المدين مع إجمالي الدائن، وبحد أدنى سطرين بمبالغ.

بعد الحفظ يظهر فورًا في دليل الحسابات ودفتر الأستاذ والتقارير.

11.14 تقرير الضريبة

يعتمد فواتير المبيعات/المشتريات في وحدة المالية — ليس اشتراكات الحضانة وحدها. لو العميل سأل عن ضريبة الاشتراكات: انظر قيود NUR-SUB-* وسطر 2030.

11.16 ربط طرق الدفع

المسار المالية → ربط طرق الدفع

كيف تشتغل؟

  1. افتح الشاشة (عادة مرة عند التأسيس أو عند تغيير البنوك).
  2. اربط إلزاميًا:
    • نقدي → حساب دليل أصول (غالبًا صندوق 1010)
    • تحويل بنكي → حساب بنك
    • بطاقة / شبكة → حساب بنك/شبكة
  3. حفظ.

لماذا مهمة؟

  • تحدد حساب المدين عند دفع الاشتراك، وحساب الدائن عند اعتماد مصروف غير نقدي.
  • بدون ربط صحيح: الترحيل يفشل أو يروح لحساب افتراضي غلط.

12) سيناريو يوم كامل تشرحه للعميل

  1. صباحًا — لوحة التحكم / حضور سريع: تسجيل حضور الأطفال.
  2. الفصول → يوم الفصل: المعلمة تتابع مين حضر وتنزل وجبة/مزاج/حفاض.
  3. الاستقبال — الاشتراكات: تسجيل دفع ولي أمر متأخر أو تجديد.
  4. الإدارة — ملخص المالية: شوف التحصيلات والمستحقات وصافي اليوم/الشهر.
  5. مصروف طارئ: مصروفات → مسودة → اعتماد.
  6. نهاية اليوم: انصراف من الحضور أو يوم الفصل.
  7. ولي الأمر: يدخل البوابة ويتابع يوم طفله والاشتراك (قراءة).
خلاصة الميتنج: كل شاشة ليها مسار واضح، أزرار عربية، وصلاحيات حسب الدور — من تشغيل الحضانة اليومي لحد المحاسبة والتقارير.
