عند شراء السيرفر — نفّذ بالترتيب:
═══════════════════════════════════════════════════════════════

1) رفع الكود ونسخ .env
   - انسخ من: ~/Backups/Production_Credentials/Akwad-Store-POS-v1.0-production.env.template.txt
   - إلى: .env على السيرفر (بعد ملء القيم الحقيقية)
   - تأكد: APP_URL=https://your-domain.com (HTTPS)

2) Database & migrations
   php artisan key:generate          # مرة واحدة إذا لم يكن APP_KEY مضبوطاً
   php artisan migrate --force

3) Storage (إيصالات التحويل البنكي + PDF)
   php artisan storage:link

4) Queue worker (WhatsApp + PDF بعد الطلب)
   php artisan queue:work --queue=default --sleep=3 --tries=3
   # أو Supervisor / systemd للتشغيل الدائم

5) Cache (بعد ضبط .env)
   php artisan config:cache
   php artisan route:cache
   php artisan view:cache

6) Paymob
   - Processed callback URL: {APP_URL}/webhooks/store/paymob
   - HMAC Secret → إعدادات المتجر → Paymob (إلزامي في Live)

7) Git (اختياري — من جهازك المحلي)
   git push origin main
   git push origin v1.0-Retail-Engine
